\# GIS-Based Flood Risk Assessment of Southwest Coastal Bangladesh



\## Project Overview



This project develops a GIS-based flood risk assessment framework for Southwest Coastal Bangladesh using a multi-criteria weighted overlay approach.



The study integrates topographic, hydrological, climatic, and land-use factors to identify spatial variations in flood susceptibility.



\## Objectives



\- Develop flood risk layers using elevation, slope, river proximity, rainfall, and land use/land cover.

\- Integrate multiple environmental factors using GIS-based weighted overlay analysis.

\- Generate a final flood risk index and classified flood risk map.



\## Data Sources



\- SRTM DEM: Elevation and slope analysis

\- CHIRPS Rainfall Dataset: Rainfall risk assessment

\- ESA WorldCover: Land use/land cover analysis

\- River Network Data: River proximity analysis



\## Methodology



The workflow includes:



1\. Data preprocessing

2\. Raster preparation and alignment

3\. Risk classification

4\. Weighted overlay analysis

5\. Final flood risk mapping



\## Weighted Overlay Model



Flood Risk Index:



FRI = (Elevation × 0.25) + (River × 0.25) + (Slope × 0.20) + (LULC × 0.15) + (Rainfall × 0.15)
